⚙️ Configuración

¿Cómo obtener el token?
1. Ve a github.com/settings/tokens
2. Generate new token (Fine-grained)
3. Repository access: All repositories (o solo las que uses)
4. Permissions: Contents: Read & Write, Pages: Read & Write, Administration: Read & Write (para crear repos)
5. Copia el token y pégalo arriba
